Create real working frontend code with a clear aesthetic direction and polished execution.

The user provides requirements, context, audience, or technical constraints.

## Process

Before coding:
- Understand purpose, audience, and constraints
- Pick a strong visual direction (minimal, brutalist, editorial, retro, luxury, playful, industrial, etc.)
- Decide what makes the interface memorable
- Match implementation complexity to the chosen aesthetic

Then build production-ready code that is:
- Functional and refined
- Visually cohesive
- Memorable and intentional
- Free of generic AI-style design patterns

## Design Principles

### Typography
- Use distinctive font pairings
- Avoid generic defaults like Arial, Roboto, Inter, and system stacks
- Combine expressive display fonts with readable body fonts

### Color
- Commit to a focused palette
- Use CSS variables/tokens
- Prefer bold contrast and intentional accents over flat balanced palettes

### Motion
- Use animation intentionally
- Prioritize impactful transitions, staggered reveals, hover states, and scroll effects
- Prefer CSS animations when possible

### Layout
- Use asymmetry, overlap, broken grids, density, or dramatic whitespace
- Avoid repetitive SaaS-style layouts

### Visual Details
- Add atmosphere with textures, gradients, shadows, patterns, blur, grain, transparency, or geometric accents
- Ensure details support the aesthetic direction

## Avoid
- Cookie-cutter UI
- Purple-gradient-on-white AI aesthetics
- Predictable component libraries without customization
- Reusing the same visual style across projects

Every design should feel custom-made for its context.
